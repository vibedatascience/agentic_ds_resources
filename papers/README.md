# Papers

Research papers, benchmarks, and evaluation work on agentic data science. Includes anything that comes with a formal evaluation, whether or not it was peer reviewed.

One file per paper, named `YYYY-MM-DD_slug.md` where the date is the publication or arXiv v1 date. Example: `2026-09-15_dsbench-v2.md`.

A paper gets a file, a blog post about a paper does not. If a company wrote a post about their own paper, the paper goes here and the post goes in `../company-blog-posts/`, cross linked.

## File format

```markdown
# Title of the paper

link: https://arxiv.org/abs/...
code: https://github.com/...
authors: First Author et al., Institution
venue: arXiv | NeurIPS 2026 | VLDB 2026
date: 2026-09-15
type: paper | benchmark | survey
tags: text-to-sql, evals
retrieved: 2026-09-21

---

The abstract as published, then any sections worth keeping in full.
```

No summaries and no commentary. For a benchmark, keep the leaderboard table as published along with the date it was read, since those move.
