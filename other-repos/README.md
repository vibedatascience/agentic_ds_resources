# Other repos

Open source projects and tools in agentic data science: analytics agents, text to SQL engines, agentic notebooks, agent harnesses that data scientists actually use, and evaluation harnesses.

Tracked as rows in the table below rather than as separate files. A project only gets its own file if you end up writing more than a paragraph about it, in which case link to that file from its row.

## What belongs here

* The project is code you could run, not a paper or a product announcement.
* It is either aimed at data science and analytics work, or it is general agent tooling that changes how data science gets done.
* Abandoned projects stay in the table with status `inactive` rather than being deleted, since knowing something was tried and stopped is useful.

## Fields

`Project` links to the repo. `Status` is `active` if it has been pushed to in the last six months, otherwise `inactive`. `Stars` and `Checked` are a snapshot from the date in `Checked`, not live numbers, so they go stale on purpose.
