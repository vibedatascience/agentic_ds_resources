## Abbreviations

| Field | Short label = codebook value |
|---|---|
| Users | all = all employees; analysts, PMs = analysts and PMs; data team = data team only; execs = executives |

| Task scope | SQL Q&A = answer a question with SQL; reports = dashboard or report creation; experiments = experiment review; multi-step = multi-step analysis |
| Context sources | code = code repos; notes = human-written domain notes; metrics = metric definitions or semantic layer; docs = past analyses or docs; queries = past queries; memory = saved corrections or memory; tables = table and column docs |
| Context delivery | prompt = always in prompt; files = curated files the agent reads; retrieval = retrieval search; tools/MCP = tool calls or MCP |
| Tools | Python = Python; SQL = SQL execution; charts = chart creation; search = search over docs |
| Eval method | LLM judge = LLM judge; question set = fixed question set with known answers; human = human review; none = none described; user feedback = user feedback |
| Trust | access = access permissions enforced; sources = cites sources; warnings = confidence or warnings; approval = human approval step; work = shows its work |
| Models | (prod) = runs the agent; (bench) = tested in the agent's harness |
