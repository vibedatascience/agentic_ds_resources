### Summary

Meta describes an internal analytics agent that grew from a prototype into a company-wide tool. It uses employees’ past SQL queries to identify relevant datasets and analytical patterns, then combines that personal context with searchable documentation, warehouse metadata, pipeline code, and semantic models.

The agent executes queries and iterates on the results, exposing the SQL behind its answers so users can inspect them. Teams package domain expertise into Cookbooks, which combine Recipes for analytical workflows and validation with Ingredients for data definitions and supporting knowledge. The post emphasizes personalized context, transparent results, reusable team knowledge, and feedback from early users.
